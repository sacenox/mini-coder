A terminal emulator runs a shell inside a window.
xterm is the classic X11 emulator.
GNOME Terminal is the default on GNOME desktops.
Konsole ships with KDE Plasma.
Alacritty is Rust and GPU based.
kitty adds graphics and tabs on top of speed.
WezTerm is scriptable with Lua.
iTerm2 is the popular macOS choice.
Windows Terminal supports tabs and panes.
tmux multiplexes terminals across sessions.
Truecolor support needs TERM set correctly.
Terminfo databases describe terminal capabilities.
